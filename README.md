# CostIQ

CostIQ is an AI spend auditing platform that helps startups and engineering teams uncover hidden costs across tools like ChatGPT, Claude, Cursor, Copilot, and cloud AI providers.

Users can enter their AI stack, plans, team size, and monthly spend to receive personalized optimization insights, savings recommendations, and shareable audit reports.

## Features

* AI spend audit dashboard
* Personalized savings recommendations
* Optimization score system
* AI-generated summaries
* Shareable audit reports
* Responsive premium SaaS UI
* Modern animations and interactions

## Built With

* Next.js
* TypeScript
* Tailwind CSS
* Framer Motion

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/costiq.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
