1. Your single North Star metric — and why
   ->
   Number of completed audits with meaningful savings
   as our project model is based on audit's and summery to the users showing their potential savings, the number of successful audits can be considered as my single North Star metric

2. 3 input metrics that drive the North Star
   -> 
   Website visitors → because more visitors means more people can start audits
   Audit completion rate → because users must finish the audit for it to matter
   Percentage of audits showing high savings → because users only become strong leads if they discover meaningful savings

3. What you'd instrument first
   ->
   What I’d Instrument First;
   
   Number of users starting an audit
   Audit completion rate
   Which AI tools/plans users enter most frequently
   Percentage of users discovering high savings
   Consultation booking clicks
   Shareable audit link usage/shares
   Drop-off point in the audit flow

4. What number triggers a pivot decision
   ->
    If less than 10–15% of users complete the audit after landing on the site, or if very few audits identify meaningful savings opportunities, I would reconsider the onboarding flow, audit logic, or target audience.
